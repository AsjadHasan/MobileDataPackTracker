# MobileDataPackTracker
A mobile operator sells monthly data packs. The pack tracks how much data has been used, and it must refuse any usage that would go over the limit.
<br>
Topics Covered:
<br>
1. Classes and Objects
2. Constructor (__init__)
3. Instance Attributes
4. Methods Calling Other Methods
5. Conditional Statements (if)
6. Early return
7. User Input (input())
8. Type Conversion (float())
9. Exception Handling (try-except)
10. while Loop
11. Data Validation
12. F-Strings and Docstrings
